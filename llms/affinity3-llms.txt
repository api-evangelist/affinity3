# Affinity Technology (The Lobby)

> Affinity Technology, Inc. operates The Lobby, an invite-only creator-marketing
> marketplace connecting direct-to-consumer brands with content creators for product
> seeding ("gifting"), paid partnerships and user-generated content. Marketing site:
> https://www.fromthelobby.com/ — application: https://tryaffinity.com/.
> This file was GENERATED by API Evangelist from the company's public site; it is not
> published by Affinity Technology.

## No public API

As of 2026-09-12 Affinity Technology publishes no public developer program. Probed and
confirmed absent on fromthelobby.com, www.fromthelobby.com, tryaffinity.com and
www.tryaffinity.com:

- /api, /api-docs, /docs, /developers — HTTP 404
- /openapi.json, /openapi.yaml, /swagger.json — HTTP 404
- /llms.txt — HTTP 404
- /.well-known/security.txt, /openid-configuration, /oauth-authorization-server,
  /oauth-protected-resource, /api-catalog, /ai-plugin.json, /agent-card.json,
  /agent.json — HTTP 404 on all four hosts
- api.fromthelobby.com and api.tryaffinity.com — DNS does not resolve
- No public GitHub organization (github.com/fromthelobby and /tryaffinity are 404)

The only integration the product advertises is a one-way Shopify connection for automated
product fulfilment and shipment tracking, configured inside the authenticated brand
dashboard. It is not a documented API a third party can call.

## Product surface (human, not machine)

- [The Lobby](https://www.fromthelobby.com/): Creator Closet, inbound request queue,
  standardized one-click partnerships, creator communities, Shopify integration,
  templates and automations, automated deliverable tracking, content library and social
  listening.
- [Creator application](https://www.fromthelobby.com/creator-application/new): creator
  sign-up (invite-only, vetted).
- [Log in](https://www.fromthelobby.com/users/sign_in): brand and creator accounts.
- [Support](https://www.fromthelobby.com/support): email-back contact form.
